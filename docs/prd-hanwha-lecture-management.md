# PRD: 한화손보 AI 강의자료 관리 시스템

## 1. 개요

한화손보 AI 강의자료 관리 시스템은 기간제 접속 코드를 통해 수강자가 강의자료와 실습자료에 접근하고, 관리자가 강좌, 접속 코드, 학습자료를 운영할 수 있는 웹 기반 강의 포털이다.

시스템은 HTML, PDF, PPT, PPTX 형식의 강의자료 업로드를 지원하며, 학습자는 강의 화면에서 강의자료를 확인하고 우측 자료 패널에서 실습 파일, 참고 링크, 외부 자료를 다운로드하거나 열람할 수 있다.

## 2. 목표

- 기간제 접속 코드 기반으로 수강 가능한 강좌만 노출한다.
- 강의 목록을 카드 형태로 제공하고, 선택 시 강의자료 화면으로 이동한다.
- 강의 화면에서 학습자료 패널을 접고 펼칠 수 있게 한다.
- 관리자가 강좌, 강의자료, 접속 코드, 자료 링크/파일을 직접 운영할 수 있게 한다.
- HTML/PDF/PPT/PPTX 강의자료를 관리할 수 있게 한다.
- PDF 기반 강의자료는 키보드로 이전/다음 페이지 이동을 지원한다.
- Vercel과 Supabase 기반으로 한시적 운영이 가능한 배포 구조를 제공한다.

## 3. 사용자 유형

### 수강자

- 사전에 안내받은 기간제 접속 코드로 로그인한다.
- 본인 코드에 연결된 공개 강좌 목록을 확인한다.
- 강의자료를 웹 화면에서 열람한다.
- 실습자료, 참고 링크, 첨부파일을 다운로드하거나 새 탭에서 연다.

### 관리자

- 관리자 코드로 로그인한다.
- 강좌를 생성하고 공개/비공개 상태를 관리한다.
- HTML, PDF, PPT, PPTX 강의자료를 업로드한다.
- PPT/PPTX 강좌에 표시용 PDF를 함께 등록할 수 있다.
- 수강자 접속 코드를 생성하고 유효기간과 활성 상태를 관리한다.
- 강좌별 학습자료와 링크를 등록한다.

## 4. 핵심 사용자 흐름

### 수강자 흐름

1. 접속 페이지에서 수강자 코드를 입력한다.
2. 코드가 유효하면 강의 목록 화면으로 이동한다.
3. 공개 상태이며 코드에 연결된 강좌 카드가 표시된다.
4. 강좌를 선택하면 강의자료 화면으로 이동한다.
5. 강의자료를 열람하고, 필요 시 학습자료 패널을 접거나 펼친다.
6. PDF 기반 자료는 키보드 또는 버튼으로 페이지를 이동한다.
7. 우측 패널에서 실습파일을 다운로드하거나 참고 링크를 연다.

### 관리자 흐름

1. 관리자 로그인 페이지에서 관리자 코드를 입력한다.
2. 관리자 대시보드로 이동한다.
3. 강좌 관리에서 강좌를 생성한다.
4. 강의자료 파일을 업로드하고 상태를 공개로 설정한다.
5. 접속 코드 관리에서 수강자 코드를 만들고 강좌와 연결한다.
6. 자료 관리에서 강좌별 실습자료, 참고 링크, 첨부파일을 등록한다.
7. 필요 시 강좌를 비공개 처리하거나 접속 코드를 비활성화한다.

## 5. 기능 요구사항

### 5.1 인증 및 접속 코드

- 수강자는 별도 계정 없이 코드로 로그인한다.
- 코드는 시작일, 종료일, 활성 상태를 가진다.
- 만료되었거나 비활성화된 코드는 로그인할 수 없다.
- 관리자는 별도 관리자 코드로 접속한다.
- 관리자 코드는 일반 수강자 코드와 분리된다.

### 5.2 강의 목록

- 로그인한 수강자에게 연결된 강좌만 표시한다.
- 강좌는 카드 형태로 표시한다.
- 비공개, 초안, 미연결 강좌는 수강자에게 노출하지 않는다.
- 강좌 카드에는 제목, 설명, 상태 정보가 표시된다.

### 5.3 강의자료 플레이어

- HTML 강의자료는 웹 화면에 iframe으로 표시한다.
- PDF 강의자료는 PDF 플레이어로 표시한다.
- PPT/PPTX 강의자료는 원본 업로드를 허용한다.
- PPT/PPTX는 표시용 PDF가 등록된 경우 PDF 플레이어로 표시한다.
- 표시용 PDF가 없는 PPT/PPTX는 원본 다운로드 안내를 제공한다.
- 강의자료 원본 다운로드를 지원한다.

### 5.4 PDF 페이지 이동

- PDF 플레이어는 현재 페이지와 전체 페이지 수를 표시한다.
- 이전/다음 버튼으로 페이지를 이동한다.
- 키보드 이동을 지원한다.
- 지원 키:
  - 다음 페이지: `ArrowRight`, `PageDown`, `Space`
  - 이전 페이지: `ArrowLeft`, `PageUp`, `Backspace`
- 입력 폼, 버튼, 링크에 포커스가 있을 때는 키보드 이동을 방해하지 않는다.

### 5.5 학습자료 사이드 패널

- 강의 화면 우측에 학습자료 패널을 표시한다.
- 패널에는 파일, 링크, 실습자료, 참고자료를 분류해 표시한다.
- 패널은 접기/펼치기를 지원한다.
- 모바일에서는 하단 플로팅 버튼으로 자료 패널을 열고 닫는다.
- 파일형 자료는 브라우저에서 미리보기보다 다운로드를 우선한다.

### 5.6 관리자 강좌 관리

- 강좌 생성, 수정, 목록 조회를 지원한다.
- 강좌 제목, 설명, 상태, 정렬 순서를 관리한다.
- 강의자료 유형을 관리한다: `HTML`, `PDF`, `PPT`, `PPTX`.
- 강의자료 파일을 업로드한다.
- PPT/PPTX 강좌에는 표시용 PDF를 추가 업로드할 수 있다.
- 기존 HTML 강좌와의 호환성을 유지한다.

### 5.7 관리자 자료 관리

- 강좌별 자료를 등록한다.
- 자료 유형은 파일 또는 링크를 지원한다.
- 파일 자료는 Supabase Storage에 저장한다.
- 링크 자료는 HTTP/HTTPS URL만 허용한다.
- 자료는 활성/비활성, 분류, 정렬 순서를 가진다.

## 6. 비기능 요구사항

### 보안

- 강의자료와 첨부파일은 공개 URL이 아닌 인증된 API를 통해 접근한다.
- Supabase Storage는 private bucket을 사용한다.
- 수강자는 본인 코드에 연결된 강좌 자료만 접근할 수 있다.
- 관리자 API는 관리자 세션이 있을 때만 호출할 수 있다.
- 업로드 파일 확장자와 Content-Type을 검증한다.

### 성능

- 강의 목록은 서버 렌더링으로 빠르게 제공한다.
- PDF는 필요한 페이지를 클라이언트에서 렌더링한다.
- 다운로드 응답은 no-store 정책을 사용한다.

### 사용성

- 메인 디자인은 여름 쿨톤 계열을 사용한다.
- 강의 화면은 상단 헤더 높이를 낮춰 자료 영역을 크게 확보한다.
- 자료 패널은 사용자가 필요할 때 접을 수 있어야 한다.
- 카드, 버튼, 패널은 업무용 시스템처럼 간결하고 명확해야 한다.

## 7. 데이터 모델

### lectures

- `id`: 강좌 ID
- `title`: 강좌명
- `description`: 설명
- `status`: `draft`, `active`, `inactive`
- `html_storage_path`: 기존 HTML 강좌 호환용 경로
- `material_type`: `html`, `pdf`, `ppt`, `pptx`
- `material_storage_path`: 원본 강의자료 파일 경로
- `display_pdf_storage_path`: PDF 플레이어 표시용 파일 경로
- `thumbnail_storage_path`: 썸네일 이미지 경로
- `uses_default_hero`: 기본 배너 사용 여부
- `published_starts_at`: 공개 시작일
- `published_ends_at`: 공개 종료일
- `sort_order`: 정렬 순서

### access_codes

- `id`: 접속 코드 ID
- `name`: 코드명
- `code_hash`: 코드 해시
- `starts_at`: 사용 시작일
- `ends_at`: 사용 종료일
- `is_active`: 활성 상태
- `notes`: 메모

### lecture_access_codes

- `lecture_id`: 강좌 ID
- `access_code_id`: 접속 코드 ID
- `sort_order`: 정렬 순서

### artifacts

- `lecture_id`: 강좌 ID
- `type`: `file`, `link`
- `category`: `practice`, `reference`, `external`, `preparation`
- `title`: 자료명
- `description`: 설명
- `url`: 링크 URL
- `storage_path`: 파일 경로
- `is_active`: 활성 상태
- `sort_order`: 정렬 순서

## 8. 파일 업로드 정책

### 강의자료

- 허용 확장자: `.html`, `.pdf`, `.ppt`, `.pptx`
- 저장 버킷: `lecture-html`
- HTML은 iframe 표시
- PDF는 PDF 플레이어 표시
- PPT/PPTX는 원본 저장 및 표시용 PDF 선택 등록

### 학습자료

- 허용 확장자: `.pdf`, `.zip`, `.xlsx`, `.pptx`, `.docx`, `.csv`, `.png`, `.jpg`, `.jpeg`, `.webp`
- 저장 버킷: `lecture-artifacts`
- 파일형 자료는 다운로드 응답을 기본으로 한다.

## 9. 배포 및 운영

- 프론트엔드/서버: Next.js
- 배포: Vercel
- DB 및 Storage: Supabase
- 운영 URL: `https://hwgi-lecture.vercel.app`
- 주요 환경변수:
  - `NEXT_PUBLIC_SUPABASE_URL`
  - `SUPABASE_SERVICE_ROLE_KEY`
  - `SESSION_SECRET`
  - `NEXT_PUBLIC_APP_URL`

## 11. 향후 개선 과제

### PPT/PPTX 자동 변환

현재는 PPT/PPTX 원본 업로드와 표시용 PDF 등록을 지원한다. 향후 외부 변환 API 또는 별도 변환 워커를 붙이면 PPT/PPTX 업로드 후 자동으로 PDF를 생성할 수 있다.

권장 방향:

- PPT/PPTX 업로드 후 변환 작업 생성
- 변환 상태 표시: 대기, 변환 중, 완료, 실패
- 완료 시 `display_pdf_storage_path` 자동 업데이트
- 실패 시 관리자에게 표시용 PDF 수동 업로드 안내

### 학습 진도

- 강좌별 마지막 열람 페이지 저장
- 수강자별 학습 완료 여부 관리
- 학습 현황 대시보드 제공

### 운영 편의

- 강좌 복제
- 자료 일괄 업로드
- 코드별 수강 강좌 미리보기
- 관리자 활동 로그

## 12. 성공 기준

- 관리자가 HTML/PDF/PPT/PPTX 강의자료를 업로드할 수 있다.
- 수강자는 코드에 연결된 강좌만 볼 수 있다.
- PDF 강의자료는 웹에서 안정적으로 페이지 단위 열람이 가능하다.
- 키보드로 이전/다음 페이지 이동이 가능하다.
- 학습자료 파일은 다운로드 방식으로 제공된다.
- 운영 URL에서 정상 접근 가능하다.
